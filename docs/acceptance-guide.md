# 受け入れ確認ガイド（T8-4）

本番: <https://orch-extras-mgmt.atsu-dq9.workers.dev>

この文書は管理者が手元でチェックリストを埋めるための手順書です。コード側の準備（T8-1〜T8-3）が終わったあと、**リリース後に実データと管理者メールを入れた状態**で確認してください。

サンプルデータのままでも「画面が動くか」の下見はできますが、受け入れ完了の判定は実データ投入後に行います。

## 事前準備（リリース後・初回）

管理画面はスマートフォンでも操作できます。PC の方が入力しやすい項目が多いです。

1. **管理者パスワード**でログインする（本番投入済み）
2. **設定**（`/admin/settings`）で問い合わせ用の管理者メールを保存する（A-7）
3. 次の順で実データを入れる（既存のサンプルは不要なら削除してから）
   - 会場
   - 演奏会（備考・出欠URL・本番日・本番会場）
   - 演奏会資料（最大5件・表示したい順）
   - 練習（日時・会場・詳細）と、終わった練習の録音リンク
   - 曲とボウイングURL（演奏順）
4. 一度ログアウトし、**エキストラ用パスワード**でもログインできることを確認する

詳細な画面の対応は [README の運用手順](../README.md#運用リリース後) を参照。

## チェック手順

各項目を確認したら `docs/tasks.md` の受け入れチェックリストにチェックを入れてください。詰まったらこのリポジトリの Issue / PR コメントで状況を共有してください。

### 1. ロール分離

- [ ] エキストラ用パスワードでログインできる
- [ ] エキストラでは URL を直打ちしても管理画面（`/admin/...`）に入れず、ダッシュボードへ戻される

### 2. 演奏会の備考・資料

- [ ] ホームに演奏会の備考が表示される
- [ ] 資料が最大5件まで、登録した順で並ぶ
- [ ] 各資料リンクを開いて正しい先に飛ぶ

### 3. 問い合わせ

- [ ] 管理者メール設定後だけ「管理者へ問い合わせる」が出る
- [ ] リンクを開くとメールアプリが立ち上がり、件名が `【<演奏会名>】エキストラからの問い合わせ` になっている
- [ ] 本文に演奏会名・氏名欄・問い合わせ内容欄のひな形が入っている

### 4. 練習日程

- [ ] 練習が一覧で日付順に並ぶ
- [ ] 「今後」と「過去」を切り替えられる

### 5. 地図

- [ ] 本番会場の住所から Google Maps が開く
- [ ] 練習会場の住所から Google Maps が開く

### 6. カレンダー

- [ ] 本番を Google カレンダーの予定として追加できる
- [ ] 練習を Google カレンダーの予定として追加できる

### 7. 練習の複製

- [ ] 管理画面で「複製して編集」すると、日付以外（時刻・会場・詳細）が新規フォームに入る
- [ ] 録音リンクは複製されない

### 8. 出欠・録音・ボウイング

- [ ] 出欠リンクから外部サービスに遷移できる
- [ ] 終わった練習に録音リンクを複数付けられ、閲覧側から開ける
- [ ] 曲ごとのボウイングが演奏順に並び、開ける

### 9. 演奏会の切り替え

- [ ] ヘッダの演奏会セレクタで切り替えると、ホーム・練習・曲が入れ替わる

### 10. パスワード変更

- [ ] 管理画面でエキストラ用（または管理者用）パスワードを変えると、旧パスワードではログインできない
- [ ] 変更したロールで開いていた別タブは、操作するとログイン画面へ戻る

本番でパスワードを変えたあとは、共有している相手に新パスワードを伝え、必要なら元に戻すか新しい値で運用を続ける。

### 11. スマートフォンとテーマ

- [ ] スマホ幅（目安 390px）で閲覧の主要操作ができる
- [ ] スマホ幅で管理の主要操作（登録・編集）ができる
- [ ] OS のライト／ダークの両方で文字が読める

## 確認が終わったら

1. `docs/tasks.md` の受け入れチェックリストをすべて `[x]` にする
2. 進捗に Phase 8 完了を追記する
3. A-7 のチェックを入れる（メールを設定済みなら）
