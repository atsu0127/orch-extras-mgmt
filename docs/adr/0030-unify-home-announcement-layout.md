# ホームのお知らせは最新・過去とも同じ左寄せカラムで並べる

## Context and Problem Statement

演奏会お知らせはホームに最新順で出す（[ADR-0022](./0022-add-concert-announcements-without-notifications.md)）。実装では最新1件だけ明朝の大きな見出しを中央寄せし、2件目以降は左寄せの狭いカラムにしていた。件数が2件になると見出しの字サイズ・揃え・本文幅が食い違い、長い本文は flex の `min-width: auto` ではみ出した。閲覧ホームのパンフレット配置に影響する。

## Considered Options

- 最新1件だけ見出しを大きく中央寄せし、過去分は左寄せの別レイアウトにする（現行）
- 全件を同じ左寄せカラム（最大幅 24rem）に並べ、はみ出しは折り返す
- 全件を中央寄せの大きな見出しにする

## Decision Outcome

採用: **全件を同じ左寄せカラムに並べ、はみ出しは折り返す**。最新であることは並び順（次の練習の直後の先頭）で示す。件数が増えても読み幅と揃えが変わらない。全件を大きな中央寄せにすると、本文の箇条書きが読みにくい。

### Consequences

- 良い: 2件以上でも日付・見出し・本文の揃えと幅が揃う
- 良い: 長い本文や絵文字付き見出しが左カラムからはみ出さない
- 悪い: 最新1件だけをタイポで強調することはやめる
