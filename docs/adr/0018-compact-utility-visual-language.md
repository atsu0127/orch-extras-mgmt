# 閲覧 UI は実用コンパクト（要約バー＋平坦リスト）とし、下部ナビはアイコン＋短いラベルにする

## Context and Problem Statement

出発案内型（ADR-0017）で情報の優先順は固まったが、暖かいアイボリー＋明朝の大きな日付ヒーローはテンプレ感が残り、一覧・他タブとの密度差も大きかった。UI UX Pro Max を用いた比較の結果、案3「実用コンパクト」と下部ナビのアイコン化を採用することにした。影響するのは設計書7.2、認証後シェル、ダッシュボード、練習・曲の一覧表現、テーマ／CSS 変数である。

## Considered Options

- 案1 時刻表スイス: モノクロ高密度・罫線中心
- 案2 演奏会プログラム: 余白と明朝の読み物 UI
- 案3 実用コンパクト: 次の練習の要約バー＋平坦なパネル／リスト（採用）
- 下部ナビをテキストのみのままにする
- 下部ナビをアイコンのみにする
- 下部ナビをアイコン＋短いラベルにする（採用）

## Decision Outcome

採用: **実用コンパクト**。クールなニュートラル背景に平坦なパネルと行リストを置き、ダッシュボード先頭に「次の練習」要約バー（日付・時刻・会場・地図）を置く。情報順は ADR-0017 のまま（次の練習 → 本番 → 出欠 → 備考・資料・問い合わせ）。明朝ディスプレイは使わずサンセリフ一本。CTA アクセントはボルドーを残す。

下部ナビは **アイコン＋短いラベル**（ホーム / 練習 / 曲。管理者は管理）。設計書7.2の「意味が明確な下部ナビは可」「アイコンだけの操作は避ける」に合わせ、アイコンのみは採らない。

時刻表スイスは冷たさが強く文化系ポータルとの相性が弱い。プログラム案は一覧・管理で冗長になりやすい。

### Consequences

- 良い: 開いた瞬間に次の練習が要約され、一覧・他タブと見た目が揃う
- 良い: タブの識別が速く、4項目（管理あり）でも下部が窮屈になりにくい
- 悪い: 大きな日付ヒーローや温かい紙色の「格」は薄くなる
- 悪い: 設計書7.2の配色・タイポ記述を更新する必要がある
