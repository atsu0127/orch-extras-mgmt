# Googleカレンダーの予定を日本時間文字列から直接組み立てる

## Context and Problem Statement

本番と練習をGoogleカレンダーへ追加する際、予定のタイトル、場所、終日予定の終了日、タイムゾーンの表現を決める必要がある。練習日時は日本時間の文字列として保持しており、`Date`を経由すると実行環境のタイムゾーンによって日付や時刻がずれる恐れがある。

## Considered Options

- タイトル・日時・会場名と住所を、日本時間文字列から直接GoogleカレンダーURLへ設定する
- タイトルと日時だけを設定する
- `Date`でUTCへ変換した日時と詳細・備考を含める

## Decision Outcome

採用: **タイトル・日時・会場名と住所を、日本時間文字列から直接GoogleカレンダーURLへ設定する**。予定を見ただけで演奏会または練習と会場を判別でき、ポータル固有の備考をカレンダーへ重複して持たせずに済む。終日予定はGoogleカレンダーの終了日が排他的であることに合わせ、翌日を終了日とする。時刻入り予定には`ctz=Asia/Tokyo`を設定し、UTC変換は行わない。

### Consequences

- 良い: 実行環境のタイムゾーンに左右されず、登録済みの日本時間どおりに予定を作成できる
- 良い: タイトルと会場情報がカレンダー上で完結する
- 悪い: Googleカレンダーの予定作成URL仕様に依存するため、外部仕様が変わった場合は追従が必要になる
