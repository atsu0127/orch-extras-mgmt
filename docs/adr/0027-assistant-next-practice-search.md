# 次の練習の検索は質問語句を無視し、ダッシュボードと同じ「今日」で明示する

## Context and Problem Statement

候補質問「次の練習はいつですか？」に、登録済みの練習があるのに「登録情報にありません」と返ることがある。Claude は1回しかツールを呼べない。Haiku は質問文を `keywords` や `concert` に載せがちで、登録テキスト（`2026-09-10の練習`）は「次の練習」を含まないため結果が空になる。システム指示に今日が無く、練習は古い順のため、件数が上限に達すると今後の練習が落ちる。

影響は `src/assistant/search.ts` の絞り込みと並び、`prompt.ts` のシステム指示、`loop.ts` の tool_result。

## Considered Options

- プロンプトだけで「keywords に質問を入れない」と指示する
- キーワード全文一致が0件なら絞り込みを外して全件返す
- 質問の言い回しを除いた実質的な語句だけで絞り込み、練習は今日以降を先に並べて次の1件を明示する。システム指示と tool_result に日本時間の今日を入れる

## Decision Outcome

採用: **質問語句の除去＋次の練習の明示＋今日の伝達**。プロンプトだけだと1回の誤った引数を取り返せない。0件なら全件返す案は、本当に無い固有語句（例: 木管分奏）でも練習一覧が渡り、無いものを答えうる。質問らしい keywords だけ無視すれば、固有語句の空結果は維持できる。

次の練習の定義はダッシュボードと同じ `date >= todayInJst()`。concert トピックの概要にも次の1件を載せ、topics を concert だけにされても答えられるようにする。

### Consequences

- 良い: 候補質問が、Claude が質問文をツール引数に載せても答えられる。30件制限で次の練習が落ちない
- 悪い: 質問語句のヒューリスティックが、演奏会名そのものが「次の練習」だけのときに選択中へ落ちる。実名として使う想定は無い
