# 練習一括はトグル・行複製・会場 modal 即保存にする

## Context and Problem Statement

練習一括作成の初期実装では、一括フォームを常時表示し、行内で会場の新規登録まで行っていた。普段使わない入力が画面を占め、似た練習を連ねるときに行のコピーができない。また会場新規を一括送信まで遅らせると、入力途中で追加した会場を他行からすぐ選べない。

## Considered Options

- 一括フォームをトグル化し、行複製ボタンを置き、会場新規は modal で即保存してセレクトへ反映する。一括 mutation から会場 INSERT を外す
- 行内の会場新規入力を残しつつ modal も併用する
- 会場 modal は出すが保存は一括送信時まで遅延する

## Decision Outcome

採用: **トグル＋行複製＋会場 modal 即保存**。一括の責務を練習 INSERT に絞り、会場マスタは既存の単件作成と同じ経路にする。行内新規との併用や遅延保存は操作が分かりにくく、要望（待たずに参照できる）にも合わない。

会場セレクトは単件と同じく「未設定」＋一覧のみとし、未設定／既存／新規のモード切替は置かない。

### Consequences

- 良い: 普段の画面が静かになる。似た行を複製しやすい。追加した会場をすぐ選べる。一括 mutation が単純になる
- 悪い: ADR-0024 時点の「行内で会場新規」とは異なる。会場作成失敗時は一括とは別のエラー表示になる
