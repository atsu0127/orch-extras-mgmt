# サークルスクエア自動同期を見送り、練習の一括作成にする

## Context and Problem Statement

エキストラ向けポータルへ、サークルスクエア上の会場・日程を取り込んで二重入力を減らしたい、という次期機能があった。調査の結果、公式 API は見当たらず、管理画面の CSV 出力は実務上使えず、iCal は日程・詳細・会場名テキストは取れるが住所付きの会場マスタには足りない。この制約のまま「同期」を実装すると、会場追加ポリシーや表記ゆれ対応が脆くなる。ポータル側の登録負荷を下げる別手段を選ぶ必要がある。

## Considered Options

- サークルスクエア iCal の半自動取込（会場は名前照合のみ）
- 管理者が用意する CSV のアップロード取込
- 管理画面での練習一括作成 UI（会場は既存選択またはその場で新規）
- 画面スクレイプ等による自動取得

## Decision Outcome

採用: **管理画面での練習一括作成 UI**。外部サービスに依存せず、今の痛い点（練習の一件ずつの登録）を直接解消できる。会場は行ごとに既存選択か新規（名前・住所）を選べる。CSV 取込は将来の拡張候補とし、初期スコープには入れない。iCal 同期とスクレイプは認証・脆さ・会場不足の理由で採用しない。

### Consequences

- 良い: 無料枠・秘密情報・利用規約の制約を抱えずに実装できる。既存の単件作成と同じ検証を再利用しやすい
- 悪い: サークルスクエア側の変更は自動では伝わらない。管理者はポータルへまとめて入れる操作が残る
