## Phase 10: 演奏会のお知らせ（完了）

選択中の演奏会に関する短い更新をホームへ掲載し、エキストラが練習前や日常に最新情報を確認できるようにする。通知や個別の既読管理は持たず、管理者が1件を1〜2分で投稿できる範囲に絞る。

| ID | 内容 | 完了条件 | 依存 | サイズ |
| --- | --- | --- | --- | --- |
| T10-1 | `announcements` のスキーマ、マイグレーション、入力検証、データ操作 | 演奏会ごとに最大10件を作成・取得・更新・削除でき、新しい順と上限を含む単体テストが通る | 初回リリース | M |
| T10-2 | 管理画面のお知らせ CRUD | タイトル・本文・任意URLを保存・編集・削除でき、演奏会切り替えでフォームが初期化される | T10-1 | M |
| T10-3 | 閲覧ホームのお知らせ表示 | 選択中の演奏会だけを新しい順で表示し、最新1件が次の練習の直後に見える。0件ならセクションを表示しない | T10-1 | M |
| T10-4 | E2E、レスポンシブ確認、README、リリース確認 | 管理者の投稿がエキストラのホームへ反映され、390px・PC幅とライト／ダークで操作・閲覧できる。全検査が通る | T10-2, T10-3 | M |

### Phase 10 受け入れ条件

- [x] 管理者がお知らせを作成・編集・削除できる
- [x] タイトル100文字、本文1000文字、URL2000文字と `http` / `https` の検証が働く
- [x] 1演奏会あたり10件を超えて登録できない
- [x] 閲覧ホームで最新のお知らせが次の練習の直後に表示される
- [x] 過去のお知らせを含む最大10件が新しい順に表示される
- [x] お知らせが無い演奏会ではセクション自体が表示されない
- [x] 演奏会を切り替えると表示内容と管理フォームが切り替わる
- [x] 任意URLがある場合だけ、既存の外部リンク表現で開ける
- [x] extra はお知らせを更新できない
- [x] スマートフォンとPC、ライト／ダークで読みやすく操作できる
