```
                                                                    Phase 8 (仕上げ)
```

Phase 2 の完了時点で「ログインすると空の画面が出る」状態になる。以降のサーバ関数は必ず middleware を通す。

ここまで来ると本番にログイン画面が出るため、A-5 を済ませて本番にも認証情報を入れる。入れないと本番へ誰も入れなくなり、以降のフェーズを本番で確認できない。

```bash
pnpm exec wrangler secret put PASSWORD_PEPPER      # openssl rand -hex 32 の出力
PASSWORD_PEPPER=<同じ値> ADMIN_INITIAL_PASSWORD=<...> EXTRA_INITIAL_PASSWORD=<...> \
  pnpm db:seed --remote
```
