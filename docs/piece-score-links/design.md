# 曲の楽譜リンク（ボウイングあり／なし）

最終更新: 2026-08-01

横断制約は [platform/design.md](../platform/design.md) を参照。タスクは [tasks.md](./tasks.md)。

## 1. 目的

1曲につき「ボウイングありの楽譜」と「ボウイングなしの楽譜」をそれぞれ外部 URL として貼れるようにする。エキストラが用途に応じて開けるようにする。

## 2. スコープ

**やること**

- `pieces` に「ボウイングなしの楽譜」用 URL 列を追加する
- 既存の `bowing_url` を画面上「ボウイングありの楽譜」として扱う（列名・既存データはそのまま）
- 管理画面の作成・編集・一覧表示を2リンク対応にする
- 閲覧画面で、設定されているリンクだけを曲ごとに出す

**やらないこと**

- パート別など3本目以降のリンク、別テーブルへの切り出し
- 楽譜ファイルのアップロード・保管（外部リンクのみ）
- `link_checks` の復活や新 `target_type` の追加（現状どおり未使用）

## 3. データモデル

| 列 | 型 | 制約 | 意味 |
| --- | --- | --- | --- |
| `bowing_url` | text | null、URL 検証（既存） | ボウイングありの楽譜。既存値はそのまま残す |
| `score_without_bowing_url` | text | null、URL 検証（新規） | ボウイングなしの楽譜 |

- マイグレーションは列追加のみ（前方互換）
- 両方とも任意。片方のみ／両方なしを許可する
- アプリ層のフィールド名は `bowingUrl` / `scoreWithoutBowingUrl`

未切り出しの旧「1曲1リンク」記述は [archive/initial/design.md](../archive/initial/design.md) に残るが凍結参照。実装の正は本文書と platform の用語・決定索引。

## 4. 画面

### 管理 `/admin/pieces`

- 入力ラベル: 「ボウイングありの楽譜 URL（任意）」「ボウイングなしの楽譜 URL（任意）」
- 一覧行でも、設定済みの方だけ外部リンクを表示する

### 閲覧 `/pieces`

- 曲名の下に、設定されているリンクだけ出す（文言は「ボウイングあり」「ボウイングなし」）
- どちらも無い曲は、行全体をリンクにせず未設定と分かる表示にする（現状の未設定行に近い）

## 5. サーバ処理

- create / update の zod・mutation に `scoreWithoutBowingUrl`（`optionalUrl`）を追加する
- 一覧 query も同フィールドを返す
- 認可は既存どおり `requireAdmin`（更新）／`requireAuth`（閲覧）

## 6. 制約

- 画面コンポーネントから `src/db/schema.ts` を直接参照しない
- URL は既存の http(s)・長さ上限に従う
- 無料プランのサブリクエスト上限を増やさない（列追加のみでクエリ本数は変わらない）

## 7. 受け入れの目安

- 管理者があり／なしの URL を別々に保存できる
- 既存の `bowing_url` は「ボウイングあり」として表示される
- 閲覧側で設定分だけリンクが出る
- 両方未設定の曲は未設定表示になる
- lint / typecheck / test が通る
